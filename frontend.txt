🔐 AUTH FLOW (FRONTEND)
────────────────────────
  1. POST /auth/login  →  { accessToken, user }
  2. accessToken → Zustand store + localStorage
  3. refreshToken → httpOnly cookie (backend sets it)
  4. Axios request interceptor → add Bearer token
  5. Axios 401 response → POST /auth/refresh → retry
  6. Logout → POST /auth/logout + clear store

🛡 ROUTE GUARDS
───────────────
  <ProtectedRoute>          — faqat login bo'lgan user
  <RoleGuard role="STUDENT">  — faqat student
  <RoleGuard role="TEACHER">  — faqat teacher
  <RoleGuard role="ADMIN">    — faqat admin

  Redirect logic:
  - Not logged in → /login
  - Wrong role → /dashboard (own dashboard)
